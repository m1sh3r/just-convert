# Структура проекта Just Convert

Репозиторий Just Convert организован в виде модульного решения на платформе .NET 10 для Windows, использующего современные языковые конструкции C# с явным контролем допустимости нулевых значений и файловыми пространствами имен.

Интерфейсная часть приложения базируется на Windows Presentation Foundation и библиотеке WPF-UI, обеспечивающей нативную интеграцию с графической темой Windows 11 и материалом слюды Mica.

## Проекты решения

Файл решения [`JustConvert.slnx`](../JustConvert.slnx) объединяет три основных функциональных проекта и отдельный тестовый модуль. Каталог исходных кодов [`src`](../src/) включает библиотеку ядра, консольное приложение с графическими окнами очереди и настроек, а также исполняемый инсталлятор.

Библиотека [`JustConvert.Core`](../src/JustConvert.Core/) реализует контракты конвертации, детекцию графических ускорителей через Windows DXGI, менеджер контекстного меню и мультиязычный словарь. Модуль [`JustConvert.Cli`](../src/JustConvert.Cli/) содержит точку входа приложения, сервер межпроцессного взаимодействия очереди IPC и пользовательский интерфейс на базе FluentWindow. Проект [`JustConvert.Installer`](../src/JustConvert.Installer/) собирает компактный автономный исполняемый установщик, распаковывающий бинарные ресурсы и настраивающий файловые ассоциации.

## Доменная структура конвертеров

Подсистема конвертации разделена на три изолированных домена в каталоге [`src/JustConvert.Core/Converters/`](../src/JustConvert.Core/Converters/). Такое разделение исключает связывание разнородных зависимостей и гарантирует, что конвертер изображений ничего не знает о мультимедийных кодеках, а аудиоконвертер не зависит от фильтров масштабирования видео.

```text
src/JustConvert.Core/Converters/
├── AudioConverter.cs          # Обработка звука (MP3, WAV, FLAC, AAC, OPUS, ALAC, AIFF)
├── VideoConverter.cs          # Обработка видео (H.264, HEVC, VP9, AV1, ProRes, GPU)
├── ImageConverter.cs          # Обработка графики (PNG, JPG, WebP, ICO, SVG, PSD, RAW)
├── OutputFileNameHelper.cs    # Форматирование имен выходных файлов и разрешение коллизий
└── Tools/
    ├── ToolLocator.cs         # Поиск утилит в вендорных путях и PATH
    ├── MediaProbe.cs          # Зондирование медиафайлов через ffprobe JSON
    ├── FfmpegInstaller.cs     # Фоновый установщик FFmpeg и FFprobe
    └── ImageMagickInstaller.cs# Фоновый установщик ImageMagick
```

Каждый конвертер реализует интерфейс [`IFormatConverter.cs`](../src/JustConvert.Core/IFormatConverter.cs) и регистрируется в едином реестре [`ConverterRegistry.cs`](../src/JustConvert.Core/ConverterRegistry.cs). Вспомогательные сервисы взаимодействия с внешними бинарными инструментами и инсталляторы сгруппированы в каталоге `Tools`.

Интеллектуальное сканирование папок, классификация разнородных медиафайлов и планирование структуры каталогов инкапсулированы в каталоге [`src/JustConvert.Core/Scanning/`](../src/JustConvert.Core/Scanning/) в классах [`FolderScanner.cs`](../src/JustConvert.Core/Scanning/FolderScanner.cs) и [`FolderBatchPlanner.cs`](../src/JustConvert.Core/Scanning/FolderBatchPlanner.cs).

## Пользовательский интерфейс и IPC

Пользовательский интерфейс приложения спроектирован так, чтобы не мешать повседневной работе в операционной системе. Окно очереди конвертации [`ConversionProgressWindow.xaml`](../src/JustConvert.Cli/UI/ConversionProgressWindow.xaml) открывается только при выполнении активных задач и автоматически закрывается по завершении, если не возникло ошибок. Для пакетной обработки каталогов используется специализированный диалог [`FolderBatchWindow.xaml`](../src/JustConvert.Cli/UI/FolderBatchWindow.xaml), позволяющий гибко задавать целевые форматы для каждой найденной категории медиафайлов.

При параллельном выделении пользователем нескольких файлов в Проводнике и выборе действия из контекстного меню каждый запущенный процесс отправляет данные первому активному экземпляру через локальный именованный канал [`ConversionQueueIpc.cs`](../src/JustConvert.Core/ConversionQueueIpc.cs). Это позволяет избежать открытия множества разрозненных окон и обеспечивает упорядоченную очередь с контролем лимита параллельных потоков.

## Подсистема логирования и диагностика

Для расследования аварийных завершений и сбоев утилит конвертации в ядре реализован автономный регистратор событий [`AppLogger.cs`](../src/JustConvert.Core/Logging/AppLogger.cs). Журналирование функционирует непрерывно как в отладочных, так и в релизных сборках, не требуя внешних библиотек и сохраняя данные в системном временном каталоге `%TEMP%` с префиксом `m1sh3r-just-convert-`.

Каждая запущенная сессия приложения формирует отдельный файл с отметкой времени и идентификатором процесса, предотвращая конфликты блокировки при одновременной конвертации нескольких очередей. В журнал записываются параметры системного окружения, пути к найденным исполняемым файлам FFmpeg и ImageMagick, полные аргументы командной строки запускаемых процессов, а также подробный диагностический вывод и трассировки необработанных исключений среды выполнения.

## Каталог тестов

Модульное и интеграционное тестирование сосредоточено в проекте [`tests/JustConvert.Tests`](../tests/JustConvert.Tests/) на базе фреймворка xUnit. Тестовые наборы проверяют полноту матриц целевых форматов реестра, валидацию профилей настроек, корректность всех строк двуязычной локализации и реальное выполнение конвертаций синтетических аудио-, видео- и графических файлов.

Инструкции по сборке и правила оформления исходного кода описаны в документе [`coding-rules.md`](coding-rules.md).
