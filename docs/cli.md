# Интерфейс командной строки

Консольный интерфейс Just Convert реализован в исполняемом файле [`just-convert.exe`](../src/JustConvert.Cli/Program.cs). Утилита поддерживает вызовы одиночной конвертации, фоновую пакетную обработку и прямое открытие настроек.

Маршрутизация параметров выполняется внутри метода запуска приложения с автоматическим разграничением интерактивного графического режима и тихого консольного выполнения.

## Одиночная конвертация файлов

Для преобразования одного файла в целевой формат используется команда с явным указанием пути к исходному объекту и модификатора целевого формата. Путь к выходному файлу является необязательным, при его отсутствии Just Convert автоматически формирует имя результата в каталоге источника с защитой от перезаписи существующих файлов.

```powershell
just-convert.exe convert "video.mov" --to mp4-h264
```

Для быстрого ремуксирования без пережатия или повторного перекодирования в тот же контейнер используются специальные целевые модификаторы:

```powershell
just-convert.exe convert "video.mkv" --to remux
just-convert.exe convert "video.mp4" --to reencode
```

При необходимости задать пользовательское имя или сохранить результат в другой каталог передается параметр назначения. Для тихой обработки без вызова графического окна прогресса применяется флаг тишины.

```powershell
just-convert.exe convert "track.flac" --to mp3 --out "D:\Music\track.mp3" --silent
```

## Пакетная обработка и списки файлов

Для массовой обработки группы файлов поддерживается передача текстового файла списка. Каждая строка такого файла должна содержать абсолютный путь к обрабатываемому медиафайлу или изображению. При использовании этого режима Just Convert автоматически удаляет временный файл списка после завершения чтения.

```powershell
just-convert.exe convert --file-list "temp_list.txt" --to webp --batch
```

Параллельные вызовы утилиты из контекстного меню Проводника автоматически объединяются через механизм межпроцессного взаимодействия IPC на базе именованных каналов, описанный в файле [`project-structure.md`](project-structure.md). Все поступившие задания встают в единую визуальную очередь окна прогресса.

## Пакетная конвертация каталогов

Just Convert поддерживает интеллектуальную пакетную обработку целых папок. При передаче пути к существующему каталогу без указания формата открывается диалог настройки пакета [`FolderBatchWindow.xaml`](../src/JustConvert.Cli/UI/FolderBatchWindow.xaml):

```powershell
just-convert.exe "D:\Photos and Videos"
```

Диалог автоматически классифицирует обнаруженные файлы по трем категориям (изображения, видео, аудио) с помощью компонента [`FolderScanner.cs`](../src/JustConvert.Core/Scanning/FolderScanner.cs), позволяет выбрать индивидуальный целевой формат для каждой категории, переключить рекурсивный поиск в подкаталогах и настроить место сохранения:

- Рядом с оригиналами (`InPlace`).
- В подпапку `Converted` с зеркалированием структуры исходных поддиректорий (`Subfolder`).

Для прямой пакетной конвертации файлов каталога через консоль используется команда с указанием целевого формата:

```powershell
just-convert.exe convert "D:\Photos" --to webp
just-convert.exe convert "D:\Music" --to mp3 --silent
```

## Запуск служебных режимов

Запуск исполняемого файла без переданных параметров или с модификатором настроек открывает графическое окно управления профилями и форматами контекстного меню.

```powershell
just-convert.exe --settings
```

Регистрация и удаление ассоциаций контекстного меню Проводника осуществляются служебными командами регистрации, которые настраивают ветки реестра Windows в соответствии с правилами менеджера контекстного меню [`ClassicContextMenuManager.cs`](../src/JustConvert.Core/Windows/ClassicContextMenuManager.cs).

```powershell
just-convert.exe register
just-convert.exe unregister
```

Подробная информация о настройке профилей и визуальных переключателях доступна в документе [`settings.md`](settings.md).
